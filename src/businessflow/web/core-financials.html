STEP 03 · CALCULATE, RECONCILE, AND TRACE

Revenue run

03 / 03

Revenue = mapped revenue account balances less mapped revenue-reduction balances, for one currency and an inclusive transaction-date window. No other measure is returned by this API increment.

To calculate a number, the selected import must be caller-asserted complete, contain no rejected or duplicate rows, and cover the report period.
