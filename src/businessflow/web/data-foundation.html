M4 → M12 · CONTROLLED EVIDENCE PROMOTION

Record an applied import

Only an already-applied M4 import with the same dataset can be linked. Each Company import can be recorded once. This creates immutable contract, quality, freshness and lineage evidence; it does not replace M4 canonical records.

UNIVERSAL DATA · GOVERNED SOURCE WORKFLOW

Universal Data Hub

Register Company-owned data sources, retain original CSV/XLSX evidence, inspect sheets and columns, version explicit mappings, validate rows, review conflicts, and promote only through an authorized human action. Records remain source-scoped and never enter Core Financials automatically.

!

Evidence and suggestions are not authority. Schema detection is advisory; it never chooses a mapping or fills missing values. Candidate matches are not merged. CSV/XLSX uploads and a configured local-directory connector are supported here. Remote ERP/CRM/API connectors, PDF extraction and scanned-document OCR are not enabled in this build.

MANUAL SOURCE · VERSIONED INTAKE CONTRACT

Customer commitment intake

Capture a person-reported customer commitment for delivery tracking. The workflow records customer name/reference, order and requested-delivery dates, a description, optional notes, and supporting files. It does not create a customer master, quote/order lines, legal agreement, accounting entry, revenue/cash-flow fact, or Core Financials record.

!

Manual assertion, not factual verification. Submission records what a Company member entered. Reviewers confirm required intake criteria and explicitly acknowledge visible warnings; review does not prove the underlying customer event, source authority, or evidence authenticity. Uploaded evidence is user-supplied; a SHA-256 hash checks file integrity only. Attachments are retained in the database and cannot be deleted in this workflow; use only approved documents.
